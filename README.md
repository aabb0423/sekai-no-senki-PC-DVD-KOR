# sekai-no-senki-PC-DVD-KOR
sekai no senki PC DVD KOR
성계의 전기 DVD판 한글화 + Windows 11 호환 패치

1. SeikaiSenki_Korean_Patch.exe를 더블클릭합니다.
2. 수정하지 않은 원본 DVD판 MDF/ISO와 영문 설치 폴더를 선택합니다.
3. 설치를 누른 뒤 바탕 화면의 ‘성계의 전기’로 실행합니다.

Python 설치나 명령어 입력은 필요하지 않습니다.
Windows 11용입니다. 시스템 로캘은 변경하지 않습니다.
게임 실행에 필요한 원본 디스크는 설치 폴더에 보관하고 자동으로 마운트합니다.
